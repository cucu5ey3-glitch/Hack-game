# Game Hacker Pro v2.0

تطبيق أندرويد متكامل لاختراق الألعاب وتعديل التطبيقات.

## المميزات الجديدة في v2.0

### تبويب Memory Hack
- بحث Exact
- بحث Fuzzy (أول مسح)
- Increased / Decreased / Changed / Unchanged
- تعديل القيمة يدوي بعد البحث
- تجميد القيم (Freeze)

### تبويب تعديل تطبيقات (خطير)
- Force Stop
- Clear Data
- Disable / Enable Package
- Kill Process
- محاولة Unlock Premium
- محاولة Remove Ads

## البناء
1. فك الضغط
2. Android Studio → Open → مجلد GameHacker
3. Sync Gradle
4. Build → Build APK(s)
5. الملف: app/build/outputs/apk/debug/app-debug.apk

## متطلبات
- جهاز Rooted
- Android 7.0+

استخدمه فقط على أجهزة تملكها أو في بيئة معملية.
